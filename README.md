Welcome to the repository of my personal web portfolio! This space is designed to showcase my journey as a Full Stack Developer, featuring my latest projects, technical stack, and contact information.

It was developed and deployed entirely for free using **v0 by Vercel**.

## ✨ Features

- **🌗 Dark / Light Mode**: Integrated using `next-themes` with a seamless toggle experience.
- **🌐 Bilingual (EN/ES)**: Custom global language context wrapper to seamlessly switch between English and Spanish without page reloads.
- **💅 Modern UI**: Built from the ground up using **Tailwind CSS** and beautifully accessible components from **shadcn/ui**.
- **⚡ Next.js App Router**: Utilizing the latest React server components and client boundaries for optimal performance.
- **📱 Fully Responsive**: Carefully crafted design that adapts from mobile screens to ultra-wide desktop monitors.

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Library**: React
- **Styling**: Tailwind CSS
- **UI Components**: shadcn/ui
- **Icons**: Lucide React
- **Hosting**: v0 (Vercel)

## 🚀 Running Locally

Want to run the project on your own machine? It's simple:

1. **Clone the repository**
   ```bash
   git clone https://github.com/menchukawaii/portfolio-web.git
   cd portfolio-web
   ```

2. **Install dependencies**
   This project uses `pnpm` as the package manager.
   ```bash
   pnpm install
   ```

3. **Start the development server**
   ```bash
   pnpm run dev
   ```

4. **Open in your browser**
   Navigate to [http://localhost:3000](http://localhost:3000) to see the result.

## 📂 Project Structure

- `app/`: Next.js App Router layout, pages, and global CSS. Includes the individual project details pages.
- `components/`: Reusable React components (Navigation, Hero, Projects, Contact, etc.).
- `components/ui/`: shadcn/ui primitives.
- `lib/`: Utility functions (e.g., Tailwind class merging).
- `public/`: Static assets like icons and images.
